# DeskMate

### Features

- **Voice and Text Commands:**  
  Interact with the assistant using both voice input and typed messages.
- **Text-to-Speech Responses:**  
  The assistant speaks its answers aloud for a conversational experience.
- **Wikipedia Integration:**  
  Fetch and summarize information directly from Wikipedia.
- **Web Browsing:**  
  Open YouTube and Google, or perform specific searches with a single command.
- **System Operations:**  
  Display the current time.  
  Create new files and folders as requested.
- **Multimedia Capture:**  
  Take photos and record short videos using the webcam.
- **AI-Powered Answers:**  
  Get intelligent responses to questions using OpenAI’s GPT-4.
- **User-Friendly Interface:**  
  Simple GUI with chat window, message box, and easy-access buttons for sending messages and activating voice commands.
- **Keyboard Shortcuts:**  
  Send messages quickly using Alt+Enter.
- **Error Handling:**  
  Clear feedback in the chat window if a command fails or is not understood.
